Практическая работа №2 (Lab\_2) 

Типы данных Python. Приведение типов. Решение задач на работу с числовыми данными.



Условия задач (Lab\_2)



Базовый уровень (A)



\- A4.py — Наибольшее из двух чисел. Программа считывает два целых числа A и B (от 1 до 1000) и выводит наибольшее из них. Запрещено использовать ветвления, циклы и функции (используется тернарный оператор).

\- A5.py — Проверка кратности. Программа проверяет, делится ли число A на число B нацело. Выводит "YES", если кратно, и "NO" в противном случае. Без использования ветвлений.

\- A6.py — Электронные часы. Программа получает количество секунд N, прошедших с начала суток, и выводит текущее время в формате h:mm:ss (часы от 0 до 23, минуты и секунды обязательно двузначные).

\- A7.py — Шахматная доска. Заданы координаты двух клеток шахматной доски. Программа определяет, покрашены ли они в один цвет. Если да — выводит "YES" и цвет (White или Black), если нет — "NO".



Практическая работа №3 (Lab\_3)



Реализация алгоритмов ветвления. Условные операторы.

Базовый уровень (A)

\- A1.py — Определение, лежат ли две точки в одной координатной четверти.

\- A2.py — Проверка надежности пароля (длина, регистры, цифры, спецсимволы).

\- A3.py — Расчет оплаты за газ по показаниям счетчика.
